    Data collection

    Catch-up, October 19 — Dream-1 changes the route from demonstrations to deployment. The technical release describes a world-action model for bimanual robots with parallel grippers, using a head view and two wrist views. Current listed model usage is $3/hour for Dream-1 and $2/hour for Dream-1-flash; these are inference prices, not data rates or total operating cost. Fine-tuning examples use each robot’s own data, with duration varying by embodiment. The model predicts end-effector targets and depends on the robot’s inverse-kinematics solver. It is a research beta with material generalisation limits. Inference: task-specific demonstrations, failure cases and adaptation evaluation remain relevant even when zero-shot transfer improves; the announcement does not disclose a supplier buying mandate.

    Catch-up, October 21 — Lattice’s sample separates captured and derived views. Its multiview reconstruction produces virtual egocentric views without a head-mounted camera. These should not be described as equivalent to native headcam recordings. The public sample includes ball handling and shirt folding with LeRobot-compatible episodes; the accessible article does not establish a commercial dataset licence. The linked dataset card could not be recovered in this pass. Publisher article.

    Research: EgoHand combines 14M images from synthetic, in-the-wild and multiview sources for monocular 3D hands. LocoManiLab supplies 234 simulation tasks and 51.5 hours of simulated teleoperation, with three matched real-world tasks; it is not a 234-task physical capture campaign. PATH studies operator preferences from 15 operators and 225 trajectories. Original abstracts and limitations appear in the research table.

    Data annotation & validation

    October 22 — physical-event labels become a sensor output. Robotiq’s 2FC platform exposes pressure, vibration and gripper-state streams with millisecond timestamps and automatic event labels. Its contact software reports grip quality, slip and related states. Model-generated labels still need validation against task ground truth; vendor output is not independent acceptance evidence.

    Research priority: RGraph-Eval checks generated robot videos through task-grounded scene graphs; SCOPE uses plan errors to revise scene graphs; Echo trains on success, failure and recovery trajectories; Progress Probes estimates runtime progress from policy activations. These support retaining failures and rework context in datasets instead of delivering only visually successful clips. Sensorimotor Alignment is an offline evaluation proxy, not a replacement for closed-loop trials. See the original papers below.

    Embedded AI systems

    October 22 — Robotiq 2FC is available for preorder, with Q1 2027 shipping planned. The published upgrade path adds touch fingertips and an AI hub to existing 2F-85/140 grippers while preserving the tool centre point. This could reduce integration friction for tactile logging; actual deployment cost and throughput still depend on the cell. Specifications.

    October 22 — NEXCOM expands RoboWIZ partner integration at GTC Berlin. The framework combines compute, vision, motion and safety engineering, with RealSense, Stereolabs, Synapticon and Reynolds & Moore. The IGX Thor-based MARS400 T20 offers eight GMSL inputs. RoboWIZ first launched in August; today’s news is the integration update, not the first existence of the platform. Component capabilities do not establish certification of an entire robot application. NEXCOM announcement.

    Catch-up, October 21 — Bear’s KINO 2 targets production manipulation. The company describes demonstration-led task adaptation and KR1 pilots, using Isaac OS/Holoscan runtime infrastructure and Thor inference. Its reported speedups use different model baselines; they are not universal end-to-end cycle-time gains. Bear’s broader installed customer footprint must not be counted as deployed KR1 manipulators. Company release.

    Research papers worth a look

    32 newly indexed preprints, original dates October 21–22. Read the original abstracts; results below are author-reported and bounded to the described experiments. Claims of planned code/data release are not evidence of current downloadable assets. Highest practical priorities are tactile capture (GelSlim 5.0, VecTile, OpenTac), human-video transfer (EgoHand, FRED, SkeLAM), and evaluation/recovery (RGraph-Eval, Echo, Progress Probes). This is not a reproduction of the experiments or a licence audit.

    2026-10-22 GelSlim 5.0: Unifying Vision and Touch with a Single Fingertip Camera GelSlim 5.0 alternates vision and touch with one camera and a UV membrane, removing inter-camera extrinsics; tested on twelve known objects.
    2026-10-22 FocusVLA: Future-Intent Guided Dynamic View Routing for Vision-Language-Action Models FocusVLA routes wrist/global views using predicted intent and history; selected real tasks improve from 71.7% to 85%.
    2026-10-22 FastHarness: Experience-Driven Review Scheduling for Vision-Language-Action Policies FastHarness schedules reviews for a frozen policy across four simulated tasks; token savings are not proof of real-time deployment.
    2026-10-22 VecTile: A Low-Cost Flexible Tactile Array for 3-DoF Force Sensing VecTile reports a flexible 4×4 three-axis tactile array below $35; design/code release is promised upon acceptance, not verified available.
    2026-10-22 Skeleton-Grounded Latent Action Model for Robot World Models SkeLAM combines explicit skeleton kinematics with residual latent actions on DROID; human-video transfer is not a demonstrated deployment.
    2026-10-22 SCOPE: Scene-graph Construction Optimized by Plan Error-correction for Robot Long-term Planning Datasets SCOPE uses plan-error correction to improve scene graphs and synthetic long-horizon planning datasets.
    2026-10-22 Echo: Coupled Action and Task Status Signal Denoising for Vision Language Action Models Echo couples action and status signals using success, failure and recovery trajectories without frame-level progress labels.
    2026-10-22 Progress Probes P2P^2: Lightweight Runtime Monitoring for Vision-Language-Action Models Progress Probes estimates task progress from policy activations using demonstrations; bounded pi0.5 simulation and real experiments.
    2026-10-22 DiffDreamer: Coupling World Models with Differentiable Simulation for Agile Quadrotor Control DiffDreamer couples a learned world model with differentiable quadrotor dynamics; includes a real-flight proof of concept.
    2026-10-22 OpenTac: An Open Ecosystem for Customizable, Scalable, and Transferable 3D Tactile Sensing OpenTac combines custom skin design, simulation and cross-sensor transfer; 19.2× speedup is for partial 16-taxel readout, not a full 1,024-taxel scan.
    2026-10-22 Sensorimotor Alignment: A Platonic Proxy for Embodied Policy Success Sensorimotor Alignment offers an offline correlation proxy for policy success, not a substitute for closed-loop evaluation.
    2026-10-21 EgoHand: Monocular 3D Hand Reconstruction from Egocentric Video EgoHand uses 14M mixed synthetic, wild-video and multiview images for monocular hands; model licensing must not be assumed to cover all raw data.
    2026-10-22 SmolVLA-MoE: Sparse Mixture-of-Experts for Efficient Multi-Task Robotic Manipulation SmolVLA-MoE uses about 500M active parameters from 800M stored; LIBERO improves to 84.25%, not a real-robot result.
    2026-10-22 DeXplicit: Making Physical State Explicit in Dexterous Manipulation World Models DeXplicit adds metric object state to dexterous video prediction; speed and error gains are relative to the stated baselines.
    2026-10-22 DRILL: Training World Models to Improve Policies, Not Predict Pixels DRILL optimises world models for downstream policy utility across five simulated settings; pixel accuracy is not the only training objective.
