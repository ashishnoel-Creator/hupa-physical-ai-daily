    Original date Paper Contribution and limit
    2026-10-20 Warping the Workspace: Expanding Visual Access with Adjustable Reach Mapping for Humanoid Teleoperation Visual-motor remapping expands humanoid teleoperation access; eight-person study favors different mappings for completion and preference.
    2026-10-20 VeriCalib: Verifiable Target-Based LiDAR-Camera Calibration Calibration uncertainty and consistency checks guide acceptance, re-extraction or recollection; low fitted residual alone is insufficient.
    2026-10-20 T-WLA: Bridging Slow Vision and Fast Touch T-WLA uses cached visual context for fast tactile corrections without rerunning vision; four real tasks average about 50% success.
    2026-10-20 Real2Sem2Real: 3D Semantic Augmentations for Robot Learning from a Single Human RGB Demonstration One human RGB demonstration generates semantic object variants; tested on two robots and four tasks, not arbitrary work.
    2026-10-20 inr2action: Encoding Robot Episodes as Neural Implicit Representations for Recall and Action Fixed-size neural episode memories support recall and action regression; RoboMME results are preliminary, not long-horizon deployment proof.
    2026-10-20 COWBOY: A Scalable Sim-to-Real Framework for Learning Contextual Whole-Body Manipulation COWBOY composes whole-body controllers and local RL experts before visual-policy distillation for contextual sim-to-real grasping.
    2026-10-20 HyperDrone: Simulation-to-Reality Transfer at Millions of Frames per Second HyperDrone accelerates multimodal batch rendering; real transfer demonstration is bounded to onboard quadrotor yaw control.
    2026-10-20 SLoSa: Small, Low-Power, and Safe Foundation Models for Robotic Task Planning SLoSa compresses safety-aware planners and reports Jetson Orin power; formal properties depend on the encoded constraints.
    2026-10-21 SimPT: An Automated Simulation Framework for Intervention-Based VLA Post-Training SimPT generates corrective simulation trajectories using privileged state and progress graphs; a cable-insertion experiment tests downstream HIL refinement.
    2026-10-21 How Representational Priors Shape Generalization in World Action Models Representational nuisance orthogonality correlates with WAM generalization; a diagnostic association rather than universal causal guarantee.
    2026-10-21 DepState-JEPA: Learning Depth-Grounded State Representation for Visual Perception and Manipulation DepState-JEPA grounds shared RGB-depth state in metric geometry and action-conditioned prediction; depth and kinematics supervision remain relevant.
    2026-10-21 Training in Deployment: Human-in-the-loop Online Post-Training for Robot Manipulation TIDE updates policies during deployment using human interventions and policy rollouts; four bimanual tasks, sessions under one hour.
    2026-10-21 Relational Geometry Forcing for World Action Models Relational Geometry Forcing transfers pairwise geometric priors during training without adding a geometry branch at inference.
    2026-10-21 A2I-Calib++: A Kinematics-Driven Anti-noise Active Calibration Framework for Whole-Body Multi-IMU Systems on Legged Robots A2I-Calib++ actively excites legged robots for multi-IMU spatiotemporal calibration, with noise-aware reference and contact modeling.
    2026-10-21 From VLM Planners to Robotic Agents: Self-Evolving Harnesses for History-Dependent Manipulation SERA revises an agent planning harness using rollouts, then freezes it before held-out testing; RoboMME success rises from 44.38% to 51.38%.
    2026-10-21 Toward Recursive Self-Improvement in Physical AI Review distinguishes behavior and procedure improvement from recursion; existing physical studies have not isolated gains attributable to recursion.
    2026-10-21 Reconstruction-Augmented Visuomotor Pre-Training of 3D-Grounded Bimanual Dexterity from RGB-Only Human Videos SpatialDex pretrains on 1M reconstructed human-video clips; geometry improves dexterity in bounded simulation and real bimanual tasks.
    2026-10-21 Post-hoc Epistemic Uncertainty for Vision-Language-Action Policies Post-hoc uncertainty heads select demonstrations or assistance from one VLA; evaluation warns task coverage can dominate benchmark rankings.
    2026-10-21 Robot Generalization Beyond Volume: The Diversity Path via Zero-Shot Capabilities Diversity-focused coverage argument and Origami community proposal; a testable hypothesis, not demonstrated commercial data-scaling results.
    2026-10-21 HuMiT: Low-Latency Whole-Body Humanoid Teleoperation via Compact Reference Tracking HuMiT uses sparse current-frame references for G1 teleoperation; about 20ms stream-to-policy differs from 65ms median video latency.
    2026-10-21 DONIC: Generalist Dexterous Bimanual Tracking Control from Human Demonstrations DONIC introduces BiHOI: 1,575 multi-view sequences and 229 objects; bimanual tracking performance drops on held-out objects.
    2026-10-21 CW-WAM: A Structured Contact-Wrench World Action Model for Force-Sensitive Manipulation CW-WAM predicts video, motion and contact wrench, pairing slow model updates with 20Hz admittance control for force-sensitive tasks.
    2026-10-21 PhysiCalWorld: In-Context Physics Calibration for World Models PhysiCalWorld conditions predictions on an exploratory interaction clip to identify instance physics; evaluated across four environments.
    2026-10-21 Agentic World Action Models AW-0 jointly generates code, video and actions, with an automated trajectory-to-program curation pipeline and reusable skill library.
    2026-10-21 DewHand: Direct Metric World-Space Hand Motion Reconstruction from Egocentric Videos DewHand jointly reconstructs metric hand/camera motion from ego video; occlusion handling and scale accuracy are evaluated, not guaranteed.
    2026-10-21 ProactEgoMem: Benchmarking Proactive Memory in Streaming Egocentric Video ProactEgoMem tests timely memory capture, object state and location tracking in 400 daily/scientific ego clips; strong models still miss events.
